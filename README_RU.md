# ECDSA // Кибер-сканер уязвимостей (TRON + BTC) v3.0

Настольное приложение для Windows x64 с понятным пошаговым русскоязычным интерфейсом в стиле киберпанк. Поддерживает анализ **CSV-файлов** (экспорт транзакций и готовых подписей), **TXT-файлов** (списки адресов кошельков и TXID), а также классическое сканирование блоков **Bitcoin Core RPC**.

## Что нового в версии 3.0

- **Умная загрузка CSV и TXT (автоопределение формата и сети)**:
  - **CSV-файлы** (например, `Transactions_*.csv` из TronScan или выгрузки BTC): автоматически распознаёт колонки (`Txn Hash`, `Block`, `Time (UTC)`, `Transaction Type`, `From`, `To`, `Token Symbol`, `Amount`, `Result`), удаляет дубликаты, показывает статистику и таблицу предпросмотра с поиском, позволяет фильтровать `SUCCESS` и конкретный адрес.
  - **CSV с готовыми подписями (`r, s, z`)**: проверяет повторы `R` мгновенно офлайн без запросов в сеть.
  - **TXT-файлы** (например, `Текстовый документ.txt` со списком адресов): автоматически определяет адреса **TRON (`T...`)**, **Bitcoin (`1...`, `3...`, `bc1...`)** и 64-символьные **TXID**, поддерживает комментарии (`#`, `//`), кириллические пути и кодировки UTF-8 / Windows-1251.
- **Поддержка сети TRON и публичного Bitcoin REST API**:
  - Для TRON используется **TronGrid / FullNode HTTP API** (`https://api.trongrid.io`, с опциональным API-ключом): по TXID из CSV запрашиваются полные транзакции, а по адресам из TXT — их исходящие подписанные транзакции.
  - Для Bitcoin поддерживаются как публичный Esplora API (`blockstream.info` / `mempool.space`), так и локальная нода **Bitcoin Core JSON-RPC**.
- **Понятный пошаговый интерфейс**:
  - Левая панель разбита на 3 шага: **1. Источник данных** → **2. Настройки и фильтры** → **3. Запуск и сохранение**.
  - Показываются только настройки выбранного режима и сети (ничего лишнего).
  - Новая вкладка **«📂 Данные файла (CSV / TXT)»** с понятной сводкой, объяснением действий сканера и таблицей предпросмотра с живым поиском.
- **Безопасная диагностика**: фиксирует пары транзакций с повтором `R`-значения и сохраняет диагностический маркер `VULNERABILITY_DETECTED_*` в SQLite, CSV и JSON (без извлечения приватных ключей).

## Быстрый запуск на Windows (без установки библиотек)

Нужен только стандартный **Python 3.10+** (внешние пакеты `pip` не требуются):

```powershell
# Двойной клик по run_windows.bat или в PowerShell:
python main.py
```

### Консольный режим (CLI)

```powershell
# Проверка CSV-файла с транзакциями TRON:
python main.py --cli -i Transactions_20261124.csv --network tron

# Проверка TXT-файла со списком адресов TRON:
python main.py --cli -i "Текстовый документ.txt" --network tron --max-tx-per-addr 200

# Классическое сканирование блоков Bitcoin Core RPC:
python main.py --cli -e http://127.0.0.1:8332 -u rpcuser -p rpcpass -s 700000 -f 700100 -t 4
```

## Сборка автономного `.exe` для Windows

### Вариант 1: Локально на Windows
Запустите `build_exe.bat` — скрипт автоматически прогонит тесты и соберёт `dist\BTC-ECDSA-Scanner-Cyber.exe`.

### Вариант 2: Через GitHub Actions (`windows-latest`)
Загрузите папку проекта в репозиторий GitHub (включая `.github/workflows/build-windows.yml`) и скачайте собранные `.exe` во вкладке **Actions** → артефакт **BTC-ECDSA-Scanner-Cyber-Win64**.
